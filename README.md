# Automated Network Request Management in ServiceNow

## Project Overview

A fully automated network request management system built on ServiceNow. It automates the entire lifecycle from submission to approval, task fulfillment, closure, and feedback collection. The solution eliminates manual coordination, provides a full audit trail, and gives all stakeholders real-time visibility.

## Features (15)

1. Dynamic UI Policies for smart form visibility
2. Auto-Create Fulfillment Task on approval
3. 8 Email Notifications across the lifecycle
4. SLA Definition with 4-hour approval tracking
5. Catalog UI Policies for dynamic behavior
6. Request Cancellation
7. SLA Breach Notification
8. Approval Reminder
9. Auto-Escalation for overdue approvals
10. Request Priority Levels
11. Three Reports
12. Management Dashboard
13. Feedback Survey
14. Update Set Deployment
15. End-to-End Testing

## Technology Stack
